# SDK Reference (moved)

This hand-written reference has been retired. The API reference is now
**generated from docstrings** and lives in [docs/reference/](reference/overview.md)
(also published at [docs.dnsid.ai](https://docs.dnsid.ai/reference/py/overview/)).

- Start at the [overview](reference/overview.md) for the import surface and
  the sync-only design notes.
- Never edit files under `docs/reference/` by hand — fix the docstring and
  regenerate with `python scripts/gen_docs.py`. See [docs/AGENTS.md](AGENTS.md)
  for the full rules.

The prose from the old reference worth keeping was ported into the package
docstrings, so it survives regeneration.
