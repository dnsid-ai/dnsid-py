# Security Policy

Identity Digital takes the security of this project seriously. This document
explains how to report a vulnerability and what you can expect from us.

## Supported versions

| Version | Supported |
| --- | --- |
| Latest tagged minor release | Yes |
| Earlier minor releases | No |

## Reporting a vulnerability

Do not report security issues through public issues, pull requests, or
discussions.

Report privately via GitHub Security Advisories: open the **Security** tab and
choose **Report a vulnerability**. If you cannot use that, email
security@dnsid.ai.

## Our commitment

- Acknowledge your report within 3 business days.
- Initial assessment (validity, severity, next steps) within 14 days.
- Keep you informed as we work on a fix.

## How fixes are released

- The fix ships as a new tagged release, with SBOM.
- We publish a GitHub Security Advisory naming the affected version range and
  the first fixed version.
- We request a CVE for Medium severity and above.
- Reporters are credited in the advisory unless they ask not to be.
